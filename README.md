# Ahmad Farhan Portfolio

Modern, premium developer portfolio built with Next.js 15, Tailwind CSS, Framer Motion, and TypeScript.

## Features

- Futuristic dark UI with neon blue and purple accents
- Glassmorphism cards and blurred gradient blobs
- Sticky transparent navbar with active section highlight
- Smooth scrolling and scroll progress indicator
- Animated reveal on scroll and hover interactions
- Custom cursor glow effect (desktop only)
- Fully responsive, mobile-first layout

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Project Structure

- src/app/page.tsx: Main portfolio UI
- src/app/layout.tsx: SEO metadata and global layout
- src/app/globals.css: Global styles and theme variables

## Customization

- Update text content, skills, and projects in src/app/page.tsx
- Replace placeholder links with your real GitHub, LinkedIn, and Instagram URLs
- Adjust colors in src/app/globals.css if needed
